# 枢游记｜互动答辩展示页

这是一套可在线或在本地查看的答辩展示材料，包含交互网页和项目界面截图。在线版：[打开枢游记展示页](https://wmzmgxnu-sudo.github.io/shu-you-ji/)。本地可双击 `index.html` 预览；若浏览器限制本地脚本或字体，可在本文件夹启动静态网页服务。

## 如何展示

1. 浏览器全屏打开首页，桌面端每个主要章节占一屏并自动吸附定位；“旅行主线”依次下滑展示出发前、旅行中、旅行后与长期陪伴。四张界面截图都按原比例显示，可点击放大。移动端保留自然阅读；系统开启“减少动态效果”时关闭吸附。
2. 到“影像修复”切换新版修复首页、去雾流程、4× 增强接口流程和手动编辑。旧版 WebView 截图已撤下；去雾与增强卡片只说明处理步骤，不会在网页中处理照片或调用后端。到“智能探索”切换知识入口、智能客服、旅行计划和旅行记忆。当前展示的应用界面均可放大查看完整原图。
3. 到“设备适配”切换手机与平板画面。平板图来自 MatePad Pro 13 模拟器里的新版修复页，保留完整画面和原始比例，点击可放大；它不代表已完成实体平板测试。
4. 点击右上角“演讲模式”打开计时、章节跳转与现场提示。
5. 最后停在“验证边界”，介绍页面保留的已验证与已实现证据；外部环境限制仍收录在完整讲稿中，不再单独占据页面一行。

## 文件

- `index.html`：页面结构与真实内容。
- `styles.css`：响应式视觉系统、动效和减少动态效果适配。
- `app.js`：旅行阶段导航状态、功能切换、大图预览、演讲模式与计时。
- `assets/`：项目截图与三张同系列无文字山水氛围背景，生成来源和用途见 `assets/manifest.json`。
- `DESIGN_REVIEW.md`：设计与测试复查记录。

页面交互在浏览器本地执行，不会上传用户数据。在线字体来自 Google Fonts；网络不可用时会回退到系统中文字体，页面内容和交互仍可用。
