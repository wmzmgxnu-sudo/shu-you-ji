# 枢游记｜互动答辩展示页

这是一套可在本地查看的答辩展示材料，包含交互网页、约 10 分钟逐字讲稿和项目真实界面截图。双击 `index.html` 可以直接预览；若浏览器限制本地脚本或字体，可在本文件夹启动任意静态网页服务。当前本机预览地址为 <http://127.0.0.1:8765/>。

## 如何展示

1. 浏览器全屏打开首页，桌面端每个主要章节占一屏并自动吸附定位；“旅行主线”的四个时刻改为页内标签切换，避免一章被拆成多屏。移动端使用更柔和的吸附并保留自然阅读；系统开启“减少动态效果”时关闭吸附。
2. 到“影像修复”依次点去雾、清晰化和手动编辑；到“智能探索”点四个场景；到“双端适配”切换手机和平板。真实界面均可放大查看。
3. 点击右上角“演讲模式”打开计时、章节跳转与现场提示。完整逐字稿见 [枢游记_10分钟答辩演讲稿.md](枢游记_10分钟答辩演讲稿.md)。
4. 最后停在“验证边界”，介绍页面保留的已验证与已实现证据；外部环境限制仍收录在完整讲稿中，不再单独占据页面一行。

## 文件

- `index.html`：页面结构与真实内容。
- `styles.css`：响应式视觉系统、动效和减少动态效果适配。
- `app.js`：旅行章节标签切换、功能切换、大图预览、演讲模式与计时。
- `assets/`：项目截图与三张同系列无文字山水氛围背景，生成来源和用途见 `assets/manifest.json`。
- `DESIGN_REVIEW.md`：设计与测试复查记录。

页面交互在浏览器本地执行，不会上传用户数据。在线字体来自 Google Fonts；网络不可用时会回退到系统中文字体，页面内容和交互仍可用。
